# Portfolio design research — applied checklist

This project uses the following recurring recommendations found across academic-profile and researcher-portfolio guidance reviewed during the v3 redesign.

1. **Clear identity above the fold** — name, research role, field and portrait are visible without scrolling.
2. **Short homepage + deeper profile** — the home page prioritizes impact and navigation; `/about` carries longer biography and credentials.
3. **Visible scholarly identity** — Google Scholar, ResearchGate, LinkedIn and GitHub are treated as primary verification links, not footer-only extras.
4. **Research outputs over generic claims** — publications, datasets, code repositories and project evidence are emphasized.
5. **Selected/current work first** — the interface highlights recent indexed works and actively maintained public repositories.
6. **Evidence-based skills** — no artificial 80/90% bars; each skill card lists tools and concrete applications.
7. **Stable research links** — DOI, publisher/source, code and dataset links are exposed where available.
8. **Readable/scannable sections** — short section intros, cards, timelines and clear heading hierarchy.
9. **Responsive/accessibility-aware interactions** — hover/pointer effects are progressive enhancement and disabled for reduced-motion users.
10. **Dedicated research biography** — education, teaching, research direction and professional identity have an indexable profile page.
11. **Maintain freshness** — teaching duration is derived from the start year and external public data is refreshed by scheduled builds.
12. **Search visibility** — localized URLs, prerendered HTML, canonical/hreflang, sitemaps, structured data and consistent name variants reinforce the Pouria Maleki / پوریا ملکی entity.

Organizations/guides compared during the redesign included Rice University, Elsevier, NC State University, London School of Economics, UC Berkeley, University of Delaware, Oregon State University, J-PAL, and additional academic-portfolio/researcher-visibility guides.
